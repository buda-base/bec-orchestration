# versions pinned in that AMI family).

# - Do NOT add `torch` / `torchvision` here — the DLAMI build is used as-is.

#   back to CPU with a logged warning otherwise (see

#   pins `requires-python>=3.14`; nothing in the vendored code

#   DINOv3 architecture on this Python/torch combination before deploying.

#   numpy>=2.0. Verify this combination actually works during smoke testing

#   — an upgrade could affect opencv-python-headless (ldv1) if venvs are
#   ever shared.
#

# BDRC/tibetan-page-orientation-classifier, BDRC/6-class-tibetan-script-classifier,
